"Qué son los elementos semánticos"

La principal diferencia entre los elementos semánticos y div y span es que los primeros tienen un significado específico en el contexto de la página, mientras que los segundos son elementos genéricos sin un significado particular.

Ahora explicaré para que sirven los siguientes elementos semánticos: header: Se utiliza para definir la cabecera de un documento o sección, y puede contener elementos como el título, el logotipo, la barra de navegación, entre otros. nav: Se utiliza para definir un bloque de navegación, que puede contener enlaces a otras páginas o secciones del sitio web. main: Se utiliza para definir el contenido principal de un documento, y debe ser único en cada página. section: Se utiliza para definir una sección de contenido relacionada, que puede contener encabezados, párrafos, imágenes, entre otros elementos. article: Se utiliza para definir un contenido independiente y autocontenido, que puede ser reutilizado en otros contextos. aside: Se utiliza para definir un contenido secundario o complementario, que puede estar relacionado con el contenido principal de la página. footer: Se utiliza para definir el pie de página de un documento o sección, y lo más normal es que incluya información como el copyright, enlaces a redes sociales, entre otros. address: Se utiliza para definir información de contacto, como la dirección de correo electrónico, el número de teléfono o la dirección física de una persona o empresa.
